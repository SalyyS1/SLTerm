Defense-in-Depth Architecture in SLTerm

      

      

        SLTerm combines a native Tauri 2 Rust host, a concurrent Go backend (wavesrv,
        pkg/agentteams, pkg/aitools, and pkg/secretstore XChaCha20-Poly1305 credential sealing),
        and an audited xterm.js frontend pipeline. Every clipboard paste passes through sanitizeAndAnalyzePaste
        before reaching the PTY, stripping 7-bit and 8-bit bracketed-paste breakouts, OSC 52 clipboard exfiltration sequences, and DCS/APC
        control strings while surfacing secret-redacted warnings.
