Defense-in-Depth Architecture in SLTerm v0.22.0

      

      

        SLTerm combines a native Tauri 2 Rust host, a concurrent Go backend (wavesrv,
        pkg/sshaudit, pkg/agentteams, pkg/aitools, and pkg/secretstore XChaCha20-Poly1305
        credential sealing), and an audited xterm.js frontend pipeline. Clipboard inputs pass through
        sanitizeAndAnalyzePaste, SSH profiles are audited against SLT001..SLT010, and exported
        terminal logs scrub live tokens into correlation-safe [REDACTED:provider#digest] handles.
